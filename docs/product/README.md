# Product

Product 文档只定义 Yakable 中稳定的产品概念和边界。

这里回答：

- 这个东西是什么。
- 用户为什么需要它。
- 用户最终能做什么。
- 哪些语义必须长期保持稳定。
- 当前明确不做什么。

这里不负责类、接口、目录、SQL、Hook 或具体施工步骤。

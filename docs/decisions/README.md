# Architecture Decision Records

Decisions 用来记录少量重要且有取舍的技术决策。

适合记录：

- 为什么选择某种协议、存储或执行模型。
- 为什么不引入某项基础设施。
- 一个长期边界为什么这样定义。
- 该决定带来的后果和限制。

不适合记录：

- 普通代码实现细节。
- 可以直接从当前 Contract / Capability 看出的内容。
- 每次小改动的过程记录。

原则：**只记录未来值得追问“当时为什么这么选”的决定。**
